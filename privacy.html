1. まとめ

このアプリは、遊びの進行や設定を、利用者の端末の中だけに保存します。提供者がそれを読むことはありません。

ただし、このアプリには動画の広告が入っています。広告を出すために、広告の配信事業者（Google）が利用者の情報の一部を取得し、同社および同社の提携先と共有します。何を取得するかは「4. 広告について」に書きます。

アプリ自身が、利用者の情報を提供者のサーバーへ送ることはありません（提供者はサーバーを持っていません）。

2. 端末の中に保存するもの

次のものを、端末の中のアプリ専用の場所に保存します。これらを外部へ送ることはありません。

何を使いみち
遊びの進行（解いたステージ、集めた絵、挑戦の記録）続きから遊べるようにするため
ゲーム内のコインの数ゲームを動かすため
ライフの数と、次に回復する時刻ライフの回復を数えるため
動画を見てライフを回復した回数（その日のぶん）1 日の回数の上限を数えるため
音楽・効果音・振動の設定、表示する言語設定を覚えておくため
表示名（自動で作る仮の名前）記録の一覧に自分の行を出すため

表示名は、アプリが自動で作る仮の名前です（例: Player123456）。ほかの利用者に見えることはありません。記録の一覧には、自分の記録だけが並びます。

3. 端末の機能の利用

  • 通知: ライフが回復したことを知らせるために、端末の通知を使います。予約は端末の中だけで行い、外部へは送りません。通知はアプリの設定、または端末の設定から切ることができます。
  • ネットワーク: 広告を読み込むために、インターネットへ接続します。

このアプリは、位置情報・連絡先・写真・マイク・カメラを利用しません。

4. 広告について

このアプリでは、次の 2 種類の広告を出します。

1. 動画の広告（ライフの回復とゲーム内のコインの受け取りのため）。見るかどうかは利用者が選べます。見なくても、ゲームは最後まで遊べます。 2. 全画面の広告（ステージをクリアしたあとに出ることがあります）。これは利用者が選ぶものではありません。

広告の配信には Google の AdMob（Google LLC）を利用しています。広告を表示・計測するために、AdMob が次の情報を取得し、Google および同社の提携先と共有します。

取得・共有されるもの使いみち
IP アドレス（おおよその位置の推定に使われることがあります）広告の配信、効果の測定、不正の防止
アプリ内での操作（広告を見た・閉じたなど）同上
診断のための情報（動作の記録、端末の種類など）同上
端末・アカウントの識別子（広告 ID など）同上

IP アドレスについて: Google は、IP アドレスを端末のおおよその位置（国や地域の程度）を推定するために使うことがあります。正確な位置情報（GPS など）は取得していません。

これらは、提供者ではなく Google が取得します。提供者が受け取るのは、配信の実績をまとめた統計だけで、個々の利用者を特定できる情報は受け取りません。

Google がこれらの情報をどのように扱うかは、同社のポリシーに従います。

  • Google のプライバシー ポリシー: https://policies.google.com/privacy
  • Google がパートナーのサイトやアプリから得た情報の使い方: https://policies.google.com/technologies/partner-sites

広告 ID は、端末の設定から削除または初期化できます。 Android では「設定」→「プライバシー」→「広告」から操作できます（機種によって場所が異なります）。広告 ID を削除すると、興味・関心に合わせた広告は表示されなくなりますが、広告そのものは表示されます。

5. 第三者への提供

提供者が、利用者の情報を第三者へ提供することはありません。「4. 広告について」に書いたとおり、広告の配信事業者が取得・共有する情報があります。これは提供者を経由しません。

アクセス解析やクラッシュ報告の仕組みは入れていません。

6. データの削除

アプリが端末の中に保存したデータは、アプリを削除すると一緒に消えます。アプリの中に「データを消す」ボタンはありません。

広告 ID は、「4. 広告について」に書いたとおり、端末の設定から削除または初期化できます。

7. 対象年齢について

本アプリは、特定の年齢層に向けて作られたものではなく、子ども向けのアプリとして提供していません。

8. 本ポリシーの変更

内容を変更するときは、この文書を更新し、最終更新日を書き換えます。アプリの作りが変わって、外部へ送る情報が増える場合は、変更後のアプリを配布する前にこの文書を書き直します。
